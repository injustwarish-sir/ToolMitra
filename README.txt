TOOLSADDA STARTER WEBSITE
=========================

Included files:
- index.html: responsive homepage and working browser-based image compressor
- privacy.html: starter privacy page; review before publishing
- contact.html: contact page; add a real contact email before publishing

HOW TO TEST ON A COMPUTER
1. Extract the ZIP file.
2. Open the toolsadda-starter folder.
3. Double-click index.html to open it in Chrome, Edge, or Firefox.
4. Select a JPG, PNG, or WebP image (up to 10 MB).
5. Choose quality, click Compress image, then Download image.

HOW TO PUBLISH FREE USING GITHUB PAGES
1. Create/sign in to a GitHub account at https://github.com/
2. Create a new PUBLIC repository named toolsadda-site.
3. Upload index.html, privacy.html, and contact.html to the repository root.
4. Open repository Settings -> Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Choose branch main and folder /(root), then Save.
7. Wait for the published site link shown in Settings -> Pages.

IMPORTANT
- GitHub Pages sites are public.
- Do not upload passwords, private documents, or personal information to the repository.
- A custom domain is optional at first. The free GitHub Pages URL can be used for testing.
- Buy toolsadda.com only after checking availability and the full renewal price at a domain registrar.
- The image compressor runs in the visitor's browser and exports JPG. Transparent PNG backgrounds become white in the JPG.
- This is a starter website, not a guarantee of Google AdSense approval or earnings.
- Before monetizing, test on mobile and desktop, add useful original content, complete privacy/contact details, and review the current AdSense policies.
