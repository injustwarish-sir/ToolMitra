Frequently asked questions

Is this image compressor free?

Yes. This starter version is free to use.

Are my images uploaded?

This tool uses your browser's built-in image processing. Your selected image is not sent to a Toolsadda server by this page.

Why is the output saved as JPG?

For broad compatibility, this version exports a JPG image. Transparent areas in PNG files will appear white in the JPG output.

Will the file always become smaller?

No. Some images are already highly compressed. If the new file is larger, try a lower quality setting.
